Ce carnet range les notes de l'équipe **map par map** : protocoles, setups de défense, exécutions, retakes, lineups, anti-strats. La map **Général** accueille ce qui vaut partout (communication, économie, temps morts).

## Prendre en main

- **Nouvelle note** (en haut à droite) : un titre, une map, un type. Chaque type démarre avec un **modèle** (rôles, timings, utilitaires…) que vous adaptez.
- **Épinglez** les protocoles clés : ils passent en tête de leur map et dans la **fiche match**, une page condensée à garder sous les yeux pendant un temps mort.
- **Collez une capture d'écran** (`Ctrl+V`) dans l'éditeur : l'image est rangée dans le carnet et insérée dans la note. Idéal pour un lineup.

## Copier, coller

- **Copier** une note, une map ou une fiche match : collez ensuite dans Discord (Markdown, tableaux alignés) ou dans Word, Google Docs, Notion (mise en forme conservée). Le bouton `[ v ]` à côté propose aussi le texte simple et le fichier Markdown complet.
- **Coller un protocole existant** : `Ctrl+V` sur une page du carnet crée une note à partir du texte copié. La mise en forme de Word ou Docs est convertie, le premier titre devient celui de la note.
- **Importer des fichiers .md** (Obsidian, un autre carnet) : déposez-les sur une map.

## Raccourcis

| Touche | Action |
|---|---|
| `/` | rechercher (filtres : `map:ascent type:retake side:def #tag`) |
| `N` | nouvelle note |
| `E` | modifier la note ou la map affichée |
| `F` | fiche match de la map |
| `C` | copier la note, la map ou la fiche affichée |
| `[` `]` | map précédente / suivante |
| `Ctrl+Entrée` | terminer l'édition (l'enregistrement est automatique) |
| `Échap` | revenir en arrière |

## Écrire

La barre d'outils de l'éditeur pose la mise en forme pour vous, et **Insérer** propose des blocs prêts (tableau des rôles, timings, checklist, encadré). Pour écrire à la main :

- Titres : `## Rôles`
- Listes : `- fumée heaven`, cases à cocher : `- [ ] veto`
- Tableaux : `| Joueur | Agent |`
- Lien vers une autre note : `[[retake-b]]`, ou vers une autre map : `[[bind/setup-a]]`
- Encadré : `> [!WARNING]` sur une ligne, puis le texte en dessous avec `>`

## Votre carnet

Tout le carnet tient dans un seul fichier, `protocol.carnet`, à côté du programme. Copiez les deux ensemble pour l'emporter ou le sauvegarder (clé USB, dossier partagé, OneDrive) : rien n'est écrit ailleurs sur le poste. Pour Obsidian ou un autre outil, l'aide propose d'exporter tout le carnet en fichiers Markdown.

Cette note peut être supprimée : elle part dans la corbeille.
